# Sandha Oil — static renderer demo

> **Generated static demo, not the Page Editor.** This is a one-off static HTML snapshot
> produced by `renderers/custom/render.mjs` from a neutral page-spec JSON. It is published to
> GitHub Pages only to show the rendered output; it is **not** the editor and has no backend.

Rendered with the second (non-Shopify) Node renderer from `renderers/custom/data/*.json`
only — no Liquid, no Shopify API call at render time. `index.html` is fully self-contained
(inline CSS; the single image is an absolute Shopify CDN URL).
